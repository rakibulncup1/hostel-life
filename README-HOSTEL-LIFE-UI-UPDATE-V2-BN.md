# Hostel Life — UI Professional Update V2

## এই প্যাকেজ কী

এই ZIP-টি ব্যবহারকারীর সর্বশেষ সরবরাহ করা `Hostel Life(2).zip` সোর্সের উপর ভিত্তি করে তৈরি করা replacement project। এটি UI/frontend-কেন্দ্রিক আপডেট। এই প্যাকেজের জন্য কোনো নতুন database migration চালানো হয়নি এবং SQL ফাইল স্বয়ংক্রিয়ভাবে চালানো হয় না।

## এই সংস্করণে করা কাজ

1. **হিসাব ইতিহাস:** সদস্যভিত্তিক scope filter (`সবার হিসাব` / `শুধু আমার`) UI, হিসাবের row-তে ক্লিক করলে বিস্তারিত modal, এবং অনুমোদিত manager ledger row-র জন্য modal থেকে সম্পাদনার action। সাধারণ সদস্যের জন্য UI-তে edit action দেখানো হয় না।
2. **History intro:** হিস্টরি পেজের উপরের ব্যাখ্যাকে সাজানো info card-এ দেখানো।
3. **Late Request card:** অনুমোদিত late/correction request-এর summary, meal-wise `+ / −` net adjustment, সবুজ/লাল রং, last-sync label, এবং গণনার সময় সতর্কতামূলক info box।
4. **Late Request details:** মোবাইল ও ডেস্কটপে modal-এর ভেতর scroll করার ব্যবস্থা।
5. **বাংলা রিপোর্টের ভাষা:** রিপোর্টের status, আর্থিক সারাংশ, জমা/খরচ, মাসিক হিসাব ও মিলের লেবেল সহজ বাংলা করা।
6. **CSV থেকে PDF-ধাঁচের রিপোর্ট:** রিপোর্ট সেকশনের UI-তে PDF লেখা এবং browser print dialog-ভিত্তিক PDF সংরক্ষণ।
7. **সদস্যের বিস্তারিত:** ড্যাশবোর্ডে সদস্যের নাম চাপলে `সকল সদস্য` পেজে যায়, নির্দিষ্ট সদস্য highlight/scroll হয়; সেখানে নাম চাপলে বিস্তারিত modal খোলে।
8. **Responsive layout:** লম্বা নামের জন্য মোবাইল header-এর wrap/overflow handling; desktop-সহ bottom navigation fixed রাখা এবং content-এর নিচে পর্যাপ্ত space।
9. **System menu:** `গোপনীয়তা ও নীতিমালা`, `ব্যবহারের শর্তাবলী`, `কীভাবে ব্যবহার করব`, `ডেভেলপার ইনফো`—নতুন menu entries এবং তাদের জন্য প্রাথমিক content card। Developer Info-তে portfolio link যোগ করা হয়েছে।
10. **Navigation/UI polish:** Dining feature card থেকে arrow icon সরানো, মেনু পেজের intro card, back button flow, এবং Manager-only eyebrow না-দেখানোর জন্য Reports/Meal Sheet-এর neutral heading।
11. **Branding:** অ্যাপের footer-এ dynamic year-সহ copyright এবং portfolio link; common report print helper-এ প্রতি পৃষ্ঠার footer text `Generated by Hostel-Life | © {year} | Developed By Rakibul Islam Samrat` যোগ করা হয়েছে, নাম portfolio-তে linked।
12. **Khala Money viewer / balance styling:** সাধারণ সদস্যের read-only summary/history presentation polish এবং বকেয়ার লেবেলের লাল styling বজায় রাখা হয়েছে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা

- **হিসাব ইতিহাসে সব সদস্যের ডেটা দেখানোর UI তৈরি হয়েছে; কিন্তু এটি একা server-side/RPC permission পরিবর্তন করে না।** বর্তমান Supabase function বা RLS যদি non-manager-কে শুধু নিজের লেনদেন দেয়, তাহলে `সবার হিসাব` নির্বাচন করলেও সব তথ্য পাওয়া যাবে না। Database investigation result পাওয়ার পরে আলাদা নিরাপদ SQL যাচাই করতে হবে। এই ZIP কোনো database permission পরিবর্তন করে না।
- বাজার এন্ট্রি/এডিটের backend সমস্যাটি এই UI প্যাকেজে সমাধান করা হয়নি; এটি আলাদা database/RPC diagnosis-এর বিষয়।
- রিপোর্টের PDF action browser-এর print dialog খোলে। সেখান থেকে `Save as PDF` নির্বাচন করতে হবে; এটি স্বয়ংক্রিয়ভাবে PDF ফাইল ডাউনলোড করে না।
- Privacy Policy ও Terms-এর লেখা **প্রাথমিক নমুনা** মাত্র, চূড়ান্ত আইনি নীতি নয়। প্রকাশের আগে প্রকৃত নিয়ম অনুযায়ী পর্যালোচনা করতে হবে।
- Offline cached data-তে browser আগে যে তথ্য সংরক্ষণ করেছে কেবল সেটুকুই দেখা যেতে পারে।

## SQL ফোল্ডার সম্পর্কে সতর্কতা

`supabase/` ফোল্ডারে আগের কাজের SQL/migration ও verification script রয়েছে। সেগুলো এই UI update ইনস্টল করার জন্য চালানোর দরকার নেই। বিশেষ করে `HOSTEL_LIFE_FEATURE_RECOVERY_V1.sql` এবং অন্য পুরোনো migration ফাইলগুলো বর্তমান live database যাচাই ও backup ছাড়া চালাবে না। এই সংস্করণে নতুন database migration যোগ করা বা চালানো হয়নি।

## ইনস্টল করার আগে

1. তোমার বর্তমান project folder-এর আলাদা backup ZIP রাখো।
2. এই ZIP extract করে নতুন folder-এ পরীক্ষা করো; সরাসরি পুরোনো ফোল্ডারের উপর overwrite করো না।
3. নিজের বর্তমান `.env.local`/credentials ফাইল নিজে নিরাপদে যোগ করো। ZIP-এ গোপন credentials রাখা হয়নি।
4. `npm ci` চালিয়ে dependency install করো, তারপর `npm run build` চালাও।
5. আগে নতুন folder-এ app চালিয়ে checklist-এর পরীক্ষা সম্পন্ন করো; সব ঠিক থাকলে তবেই নিজের deployed project update করো।
