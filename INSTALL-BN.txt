HOSTEL LIFE — RUN69 FULL BILINGUAL CUMULATIVE PATCH
=====================================================

এই প্যাকেজটি প্রথম আপলোড করা “Hostel Life(1).zip” প্রজেক্টের ওপর ভিত্তি করে

ইনস্টল
------
1. প্রথমে বর্তমান project folder এবং Supabase database-এর backup নিন।
2. ZIP extract করুন। এর ভেতরের “Hostel Life/” folder-এর contents আপনার
   মূল project root-এ copy/overwrite করুন।
3. `.git`, `node_modules` বা আগের `dist` folder replace করার দরকার নেই।
4. project root থেকে চালান:

   npm ci
   npm test
   npm run build

5. Build সফল হলে আপনার স্বাভাবিক deployment process অনুসরণ করুন।
